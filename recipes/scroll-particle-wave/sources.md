# Scroll particle wave - sources

## Where it was found
- **Facebook reel** by Gobinda Das, found 10/22/26: [share link](https://www.facebook.com/share/r/1FHSPTpe7Y/) (opens as `facebook.com/reel/4603014396607659`). Caption read in Nick's logged-in Chrome on 10/22/26.
- **Caption, in summary:** a website of 9,000 points that become a wave on scroll. Three tools, one job each: Three.js draws, Framer Motion turns scroll into a 0-to-1 number, Claude wrote the shapes, shader and timing. The trick is reading that number in the frame loop so React doesn't re-render while scrolling. Voiceover is AI (ElevenLabs).

## The creator
