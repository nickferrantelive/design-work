# Three.js - roadmap

_Written 10/22/26._

## Recommendation: try
Free, mature and well known to Claude. Try it through a recipe rather than on its own, so the first test produces something usable.

## Steps (free first)
1. Build the [scroll particle wave](../../recipes/scroll-particle-wave/roadmap.md) test page. That exercises the core of Three.js: points, shapes, a shader and an animation loop.
2. Check it on a phone. Set a lower particle count for small screens before using it anywhere real.
3. Keep a short list of other effects worth trying (3D product views, logo reveals, animated backgrounds), each filed as its own recipe when it comes up.

## Where it would fit
- Hero sections and brand moments on Nick's sites, where motion is part of the brand, such as the AI agency site.
- Less of a fit where speed and plain clarity matter most, such as consumer education pages.

## What would change the verdict
- A no-code tool that makes the same effects without code would beat it for quick tests.
- Phone performance that can't be fixed with a lower particle count would limit it to desktop-only moments.
