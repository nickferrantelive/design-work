# Claude - roadmap

_Written 10/22/26._

## Recommendation: adopt (already in use)
Use Claude as the builder for every recipe test page here.

## Steps
1. For each recipe, describe the effect and its feeling first, then have Claude build a throwaway test page.
2. Record in the recipe's roadmap what Claude got right first time and what needed fixing, so later recipes start from that.

## What would change the verdict
- Recipes where Claude repeatedly can't get the effect right without heavy hand-fixing.
